# Dr. H.E. Maepa Institute Digital Ecosystem

A full-stack-style Next.js website for the Dr. H.E. Maepa Institute Digital Ecosystem. It includes church live service, PV solar training, marketing services, a mock shop, leadership academy membership, simulated checkout flows, and a React Three Fiber hero with a GLTF model plus static fallback.

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production

```bash
npm run build
npm start
```

The project is ready to deploy to Vercel or Netlify by pushing to GitHub and connecting the repository.

## Integrations

All payments and forms are simulated:

- `/api/checkout` returns mock redirect URLs for Stripe, PayFast, SnapScan, shop, course, and subscription flows.
- Prayer requests and marketing/contact inquiries log details to the browser console and show a thank-you state.
- Dashboard access uses a local mock auth flag in `localStorage`.
- Certificate downloads are generated by `/api/certificate`.
